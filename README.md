# Khushi & Pranay - Wedding Invitation (Exact 1:1 Clone)

Exact point-to-point clone of [khushi-pranay.invitationmedia.in](https://khushi-pranay.invitationmedia.in/).

## Structure

- `index.html`: Main HTML entry point with metadata, Google Fonts, and assets.
- `assets/`:
  - `index-BgkQTLfu.js`: Application logic and UI interactions.
  - `index-BC6_D4MB.css`: Complete styling, animations, and Tailwind design tokens.
  - `envelop-sr7wwrnc.png`: Opening envelope artwork.
  - `logo1-CEx21hqH.png`: Header couple monogram/logo.
  - `mainbg-C1qdEah8.jpg`: High-resolution background texture.
  - `pathbithai-mN0HwaUc.png`: Paath Bithai illustration.
  - `sanget-Bz6_t-zi.png`: Sundowner Sangeet illustration.
  - `varmal-C8h79Pnd.png`: Baarat Swagat & Varmala illustration.
  - `phere-LBZBKn6h.png`: Phera ceremony illustration.
  - `recept-CMr8tXBs.jpg`: Reception celebration artwork.
- `audio/`:
  - `background.mp3`: Background wedding instrumental music (with audio streaming / range request support).
- `server.js`: Lightweight local web server supporting all MIME types and audio seeking.
- `package.json`: Project scripts.

## How to Run

1. Open a terminal in this directory:
   ```bash
   npm start
   ```
   or
   ```bash
   node server.js
   ```

2. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
